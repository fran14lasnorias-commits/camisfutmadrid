# Lista de lanzamiento

## Obligatorio antes de abrir pedidos

- [ ] Dominio comprado y conectado.
- [ ] Supabase creado y migraciones ejecutadas.
- [ ] Primer administrador configurado.
- [ ] Stripe verificado y webhook funcionando.
- [ ] Cuenta bancaria configurada en variables privadas.
- [ ] Correo transaccional verificado.
- [ ] Catálogo real cargado.
- [ ] Stock correcto por talla.
- [ ] Prueba de compra con tarjeta.
- [ ] Prueba de transferencia.
- [ ] Prueba de cupón.
- [ ] Prueba de cancelación y devolución de stock.
- [ ] Aviso legal completo.
- [ ] Privacidad completa.
- [ ] Cookies completas.
- [ ] Condiciones y devoluciones completas.
- [ ] Datos fiscales y contacto visibles.
- [ ] Revisión de derechos de uso de imágenes, marcas y productos.
- [ ] Copias de seguridad y alertas.
- [ ] La ruta `/api/readiness` devuelve `ready: true`.

## Recomendado

- [ ] Google Search Console.
- [ ] Analítica con consentimiento.
- [ ] Dirección de devoluciones.
- [ ] Política antifraude.
- [ ] Pedidos de prueba desde móvil.
- [ ] Revisión de accesibilidad.
